## 3. 主题系统现状（改动前必读）

### 3.1 取色三层

1. **`ThemeColors`**（`com.oilquiz.app.theme`）：
   - `ATTR_BY_RES`：颜色资源 → 主题 attr 的映射表，**当前 65 条**，被
     `src/test/java/com/oilquiz/app/theme/ThemeColorsMappingTest#mappingTableSizeIsPinned` 钉死；
     加/删映射必须同步改测试数字并写明理由。
   - `ThemeColors.get(ctx, R.color.x)`：查表走 attr，缺 attr 退回资源值（**不会抛**）。
   - `ThemeColors.attr(ctx, R.attr.colorX)`：直接解析 attr。
2. **`ComponentColors`**（`ai/chat/component`）：卡片渲染用的语义取色（background/border/
   textPrimary/textSecondary/textTertiary/accent/success/error/warning/fieldBg/chartColor…）。
3. **`ThemeManager` + `res/values/theme_overlays.xml`**：7 个预设色 + 自定义色 + 深色/OLED，
   运行时 `ThemeOverlay` 注入；XML 里一律用 `?attr/colorXxx` 才能跟随换肤。

### 3.2 设计令牌

- `res/values/dimens.xml`：`space_N`（1..100）、`size_N`（含 0.5）、`radius_N`、`font_*`（语义层级
  10/11/12/13/14/15/16/18/20/24sp）、`text_*` 等。
- `Tokens`（`com.oilquiz.app.theme`）：`space/dp/radius/textSizePx/textSizeSp/applyText` 等 API；
  Java 字号统一 `Tokens.textSizeSp(view.getContext(), Tokens.TEXT_*)`。
- **约定**：新代码不允许再出现 `0xFF...`/`#...`/`@android:color/white|black`、不写死 dp/sp。

## 6. 坑与注意事项（踩过的）

0. **护栏测试**（改 UI 先跑）：
   - 注意：夜间**样式**单源（values-night/styles.xml 已清空），夜间只该有 colors/theme_overlays；
     别再在 values-night 里复制样式，否则会和浅色漂移、深色模式 attr 解析失败（见 `80a0e5a9`）。
`UiHardcodeGuardTest`（对话页颜色/尺寸/字号 + 调试台调色板）、
   `ThemeAttrCoverageTest`（`?attr/colorXxx` 必须有定义）。改对话页或加 attr 后先跑它们；
   护栏失败通常就是真问题，不要先改护栏。

1. **XML `?attr/...` 必须有应用主题**：Robolectric 里裸 `ApplicationProvider.getApplicationContext()`
   解析不到 attr，inflate 抛 `Failed to resolve attribute`。新写/改测试要用
   `com.oilquiz.app.testsupport.ThemedAppContext.get()`（见 `PartsCoverageTest`）。
2. **`R.attr.colorPrimaryVariant` 不存在**于 app 的 `R.attr`，要用
   `com.google.android.material.R.attr.colorPrimaryVariant`。
3. **`ThemeColorsMappingTest` 钉死映射条数 65**：改 `ThemeColors` 映射必须同步改测试并写理由。
4. **产品口径不能靠"把测试改绿"绕过**：出卡口径以桥的 `forward` 为准；内部事件
   （hook/feedback/model-selection/assistant-attempt）不出卡；`job/settled` 只在失败/取消时留卡。
5. **媒体查看器的纯黑底/白图标是有意的**（全屏看图、视频播放），不要接主题。
6. **Robolectric 会注册 Conscrypt**，单测不得真连 TLS（`WebFetchPolicy` 走可注入 fetcher）。
7. **golden prompt 快照**：`src/test/resources/golden/{assist,takeover}.txt`，改提示词行为要同步重生成。
8. `git commit -F` 与 `git push` 会往 stderr 打 CRLF/远端地址，**exit code 0 即成功**。
9. 提交信息用中文、写清根因；一改一提交；文档与代码同批更新。
10. **真机截图**：PowerShell 里 `adb exec-out screencap -p > x.png` 会把二进制写坏（图片无法解码），
    改用 `adb shell screencap -p /sdcard/s.png` + `adb pull /sdcard/s.png x.png`。
11. 真机 `279b6c51` 常被用户使用中（截图时前台是 DSH 自身），装 APK 前先确认用户空闲/同意。
