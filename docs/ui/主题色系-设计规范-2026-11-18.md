# 主题色系设计规范（2026-11-18）

> 口径：**品牌色值不动，补全角色体系**。默认主题保持现有紫 / 青 / 琥珀与 slate 中性色；
> 预设主题（7 精致色 + 24 色相网格）由 HCT 生成器产出同一套角色。
> 本文是「主题色系」的唯一取值口径；改色先改这里，再改 `colors.xml` / 生成器。
>
> **默认选中色（2026-11-18 产品口径）**：主题设置页默认选「蓝色」（`COLOR_BLUE`，应用
> `ThemeOverlay.SmartQuiz.Blue`），**不改任何色值**。旧版本默认紫、且用户没手动选过色的数据，
> 由 `ThemeManager.getThemeColor` 一次性迁到蓝色（带 `theme_color_picked` 标记，手动选过色的不动）。

- 之前的状态：角色只补了一部分，默认主题与预设主题两套色、`colorDivider` 还指向组件描边、
  `info` 语义浅色借主紫 / 夜间借蓝、语义 on 色在浅色下大面积不达标。
- 现在的状态：品牌 / 中性 / 表面 / 边框 / 文本 / 状态 / 语义 / 图表 / 遮罩 九组角色完整，
  深浅 + OLED 三档齐全，预设 overlay 自带全部角色，对比度有测试钉住。

---

## 0. 设计原则

1. **角色优先，色值其次**：组件只认 `?attr/colorXxx`，不认 hex；同一角色在深浅/换肤下必须是同一个语义。
2. **一层一档**：表面按 elevation 分档，边框分三档，文本分四档；层级靠 token 递进，不靠各组件自己算 alpha。
3. **对比度是验收项**：正文 4.5:1、组件描边/图形 3:1；不达标就改角色值，不靠"看起来还行"。
4. **语义色跨皮肤不变**：成功/警告/危险/提示（含容器）不随品牌色换肤，保证状态语义稳定。
5. **数据可视化固定色板**：图表系列色不随皮肤变（皮肤只影响网格/轴线/标签），避免容器色被当数据色。
6. **品牌例外显式记录**：白字压主紫 `#8B5CF6` 是 4.23:1，仅用于 ≥16sp 按钮/大标题/图标，
   正文链接请用 `colorPrimaryDark`（`#7C3AED`，5.70:1）。

## 1. 色系总览

| 组 | 角色（attr） | 用途 |
|---|---|---|
| 品牌 | `colorPrimary` / `colorSecondary` / `colorTertiary` + `Container` + `On*` | 主操作、选中、强调、品牌标识 |
| 中性表面 | `colorBackground` / `colorSurface` / `colorSurfaceDim` / `colorSurfaceBright` | 页面底 / 卡片面 / 压低 / 抬高 |
| 表面层级 | `colorSurfaceContainerLowest…Highest`（5 档） | 卡片、弹层、输入框、列表项的分层 |
| 边框 | `colorOutline` / `colorOutlineVariant` / `colorBorder` / `colorBorderStrong` | 组件描边 / 分隔线 / app 卡片边框 / 强边框 |
| 文本 | `colorControlText` / `…Secondary` / `…Tertiary` / `…Hint` / `…Disabled` | 正文 / 次要 / 弱化 / 占位 / 禁用 |
| 状态 | `colorStateHover` / `Focus` / `Pressed` / `Dragged` / `DisabledContainer` / `DisabledContent` | 交互态叠加层 |
| 语义 | `colorSuccess` / `colorWarning` / `colorDanger` / `colorError` / `colorInfo` + `Container` / `On*` | 结果、风险、提示 |
| 图表 | `colorChart1…8` / `colorChartGrid` / `colorChartAxis` / `colorChartLabel` | 数据可视化 |
| 反色/遮罩 | `colorInverseSurface` / `OnSurface` / `Primary`、`colorScrim` | Snackbar / 反色浮层 / 弹层遮罩 |

- 浅色：`lowest` 最亮、层级越高越暗；夜间反过来。

  浮层底座用 `colorSurfaceBright`。
- 不要再写 `#FFFFFF` 或 `alpha 0.12`。

### 3.2 边框三档（+ 描边）

| 角色 | 语义 | 浅色 | 夜间 | 预设生成 |
|---|---|---|---|---|
| `colorOutlineVariant` | 分隔线 / 最弱边框 | `#E2E8F0` | `#2F2947` | neutralVariant tone 80 / 30 |
| `colorBorder` | app 卡片边框（= variant） | `#E2E8F0` | `#3A3157` | outlineVariant |
| `colorBorderStrong` | 强边框（选中/L3 标签） | `#CBD5E1` | `#4A4166` | neutralVariant tone 75 / 35 |
| `colorOutline` | **组件描边**（Chip/输入框/日期选择器） | `#64748B`（4.76） | `#8A82A0`（4.71） | neutralVariant tone 50 / 60 |
| `colorDivider` | 分隔线 attr（= variant） | `?attr/colorOutlineVariant` | 同 | outlineVariant |

> 铁律：`colorOutline` 只给组件描边；分隔线/`android:background` 细线用
> `colorDivider` 或 `colorOutlineVariant`。两者互换就是 2026-11-18 之前那个"全站分隔线变深灰"的 bug。

## 9. 验收

- `ThemeColorRolesTest`：默认主题 11+ 个 M3 角色深浅都能解析；预设 overlay 自带五档容器且明暗有序；
  outline ≠ outlineVariant；surfaceContainer 方向正确。
- `ThemeContrastTest`：16 组 on/base 文字对 ≥4.5（品牌主色例外 4.23 单列）；
  outline/图表系列对表面 ≥3；colorDivider == outlineVariant。
- `ThemePaletteTest`：7 预设 + 色相网格种子，五档容器齐全/有序、边框三档有序、on 色方向正确。
- `ThemeColorsMappingTest`：映射表规模与逐条语义（`outline → colorOutlineVariant`、
  `text_tertiary → colorControlTextTertiary`）。
- 真机：`ThemeAuditActivity`（`--es mode theme_audit`）核对色块；画布日期/时间选择器、
  Chip、Card、Snackbar 看 M3 角色；再切 7 预设 / OLED 看层级。
