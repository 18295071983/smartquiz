## 12. 备注

- `okhttp 4.x` → `okio 3.x` → `kotlin-stdlib` 是传递依赖，所以 APK 里一定有 Kotlin 运行时；这与“业务源码纯 Java”不冲突。
- 重复声明已清理；`:viewer` 模块自己也声明了 flexbox，所以依赖树里该模块仍显示两次（一次直连、一次 `(*)`），属正常。
- APK 大块头是资源不是依赖：ASR 模型 228 MB、`liblo-native-code.so` 171 MB、termux 108 MB、Chaquopy 64 MB、llama 39 MB。
