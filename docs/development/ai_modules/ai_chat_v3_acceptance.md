## 1. 功能验收标准

### 1.1 深度思考模式

| 测试项 | 验收标准 | 优先级 | 测试方法 |
|--------|---------|--------|---------|
| 模式切换 | 用户可手动切换到深度思考模式 | 高 | 手动操作测试 |
| 自动识别 | "为什么"、"如何"、"解释"等关键词自动触发深度思考 | 高 | 输入关键词测试 |
| 思考步骤显示 | 显示完整思考链：理解→分解→知识→评估→推理→验证→综合 | 高 | 观察UI显示 |
| 进度指示 | 每个步骤有进度指示 | 高 | 观察进度条/百分比 |
| 置信度显示 | 显示当前置信度百分比 | 中 | 观察UI |
| 推理深度 | 显示推理深度（层数） | 中 | 观察UI |
| 折叠/展开 | 支持思考过程折叠和展开 | 中 | 手动操作测试 |
| 最终答案 | 思考完成后显示最终答案 | 高 | 端到端测试 |
| 流式更新 | 思考过程实时更新，无延迟 | 高 | 观察更新流畅度 |

**验收测试用例**：
1. 手动切换到深度思考模式，发送问题
2. 输入"为什么天空是蓝色的"，观察自动触发深度思考
3. 观察思考步骤是否完整显示
4. 验证最终答案是否基于思考过程

### 1.2 创意写作模式

| 测试项 | 验收标准 | 优先级 | 测试方法 |

### 1.3 模式切换功能

| 测试项 | 验收标准 | 优先级 | 测试方法 |
|--------|---------|--------|---------|
| 手动切换 | 支持手动切换四种模式（普通、深度思考、Agent、创作） | 高 | 手动操作测试 |
| 立即切换 | 非生成状态下立即切换 | 高 | 非生成时切换 |
