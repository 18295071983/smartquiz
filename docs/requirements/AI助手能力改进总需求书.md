## 0. 文档说明

本总需求书整合 AI 助手在 **界面呈现、工具调用、记忆系统、多轮对话、决策规划、文件工作区、性能容错、安全确认、语音多模态、个性化主动性** 十大维度的改进诉求，是 AI 能力层建设的统一依据。

原《UI 组件系统改进需求文档》《工具调用体系改进需求文档》的内容已并入本文档，作为**维度一、维度二**，详见对应分册。

## 一、总体目标

让 AI 助手从「能用」走向「好用、稳定、可预期」：



1. 降低选型与试错成本（工具、组件不再靠瞎猜）；

2. 提升交互与交付的确定性（预览、校验、统一结构）；

3. 增强长程任务的连贯性与安全性（记忆、状态、确认）。

## 三、分维度需求

### 维度一　UI 组件系统（详见分册）



* **P0**：布局实时预览 + 创建前校验；参数前置校验与精确定位；字段命名规范化。

* **P1**：异步回传体验优化；三条能力路径边界厘清；样式控制增强；组件生命周期与 id 管理。

* **P2**：响应式适配；错误定位与调试；交互反馈。

### 维度二　工具调用体系（详见分册）



* **P0**：工具命名与元数据规范化；参数 schema 统一与调用前校验；返回值结构统一。

* **P1**：错误处理规范统一；工具选型指引 / 智能推荐；权限与调用联动。

* **P2**：耗时预估与并行提示；大结果分页 / 截断提示；工具说明与示例完善。

### 维度三　记忆系统

**现状痛点**



* 记忆为扁平 key-value 结构，无法存储结构化 / 关联信息，缺语义检索；

* 每次会话全量注入记忆摘要，无相关性筛选，Prompt 膨胀；

* 无时效、过期与冲突处理机制，旧信息不会自动失效；

* 保存依赖模型自觉判断，易漏存或误存；

* 用户查看 / 管理记忆的入口弱。

**改进需求**



* **P0-1 记忆结构化与分类**：支持分类（事实 / 偏好 / 情境）与结构化存储。

* **P0-2 保存规则明确**：明确「何时存、何时不存」，降低漏存 / 误存。

* **P1-1 记忆时效与冲突处理**：支持 TTL / 过期与同 key 更新冲突策略。

* **P1-2 相关性筛选注入**：按当前语境筛选相关记忆注入，控制 Prompt 体积。

* **P2-1 记忆管理界面**：用户可查看 / 编辑 / 删除记忆。

**验收标准**：记忆可按类别管理；旧信息可自动失效；注入内容与语境相关；用户可自助管理。

### 维度四　多轮对话连贯性

**现状痛点**



* 长对话依赖摘要压缩，细节丢失；

* 无任务 / 对话状态跟踪，多任务并行易混乱；

* 上下文窗口限制导致早期信息遗忘；

* 长对话中指代消解（「那个」「它」）易出错；

* 会话无法分支或回滚。

**改进需求**



* **P0-1 任务状态跟踪**：维护任务清单（进行中 / 完成 / 待办），跨轮保持。

* **P1-1 关键信息锚定**：核心事实不随摘要压缩丢失。

* **P1-2 指代消解增强**：长对话中准确还原指代对象。

* **P2-1 对话分支 / 回滚**：支持撤销与分支。

**验收标准**：长对话关键信息不丢；任务状态清晰；指代准确；可回滚。

### 维度五　决策与规划

**现状痛点**



* 多步任务中途失败后恢复 / 回退机制弱；

* 决策过程对用户黑盒，不知进度；

* 「该问用户还是自己做」边界不清，可能过度打扰或擅自行动；

* 缺长任务进度可视化。

**改进需求**



* **P0-1 自主边界规范**：明确何时必须确认、何时可自主执行。

* **P1-1 长任务进度可视化**：多步任务展示进度与当前步骤。

* **P2-1 失败回退与重规划**：失败后可回退并重新规划。

**验收标准**：确认与自主边界清晰一致；长任务进度可见；失败可恢复。

### 维度六　文件与工作区

**现状痛点**



* 相对 / 绝对路径易混；

* 生成文件用户不便直接找到 / 分享；

* 大文件处理与格式转换支持有限；

* 无文件版本管理。

**改进需求**



* **P0-1 工作区可见性与分享优化**：文件易于查找、预览与分享。

* **P1-1 格式转换增强**：支持更多格式互转（md/pdf/xlsx/csv 等）。

* **P2-1 文件版本管理**：保留历史版本，避免覆盖丢失。

**验收标准**：文件易找到与分享；常用格式可转换；覆盖有版本兜底。

### 维度七　性能与容错

**现状痛点**



* 长任务无进度反馈，用户干等；

* 失败重试策略不统一；

* 并发调用控制不透明。

**改进需求**



* **P0-1 长任务进度反馈**：耗时操作主动反馈进度。

* **P1-1 统一重试与降级策略**：明确可重试与降级路径。

* **P2-1 并发编排优化**：合理并行、明确顺序约束。

**验收标准**：长任务有进度；失败有统一处理；并发可控。

### 维度八　安全与确认

**现状痛点**



* 不可逆操作（删除 / 覆盖 / 发送）的确认依赖模型自觉，缺系统级强制；

* 敏感数据（定位 / 通讯录等）使用边界不清；

* 工具返回的网页 / 文件内容存在提示注入风险。

**改进需求**



* **P0-1 不可逆操作强制确认**：系统级拦截并强制二次确认。

* **P1-1 数据使用边界与最小化**：敏感数据按需申请、最小使用。

* **P2-1 注入内容标记与隔离**：外部内容与指令隔离，防注入。

**验收标准**：不可逆操作必确认；敏感数据使用受控；注入风险有防护。

### 维度九　语音与多模态

**现状痛点**



* 语音模式需手动切换；

* 方言 / 口音识别效果一般；

* 图片等多模态输入的能力边界未说明。

**改进需求**



* **P0-1 语音交互体验优化**：降低进入门槛，更顺畅。

* **P1-1 多模态输入支持说明**：明确可处理的输入类型与边界。

* **P2-1 方言 / 口音适配**：提升识别鲁棒性。

**验收标准**：语音交互顺畅；多模态能力边界清晰；识别鲁棒性提升。

### 维度十　个性化与主动性

**现状痛点**



* 不主动提醒 / 推送，除非用户开口；

* 个性化偏好应用不充分；

* 缺主动建议能力。

**改进需求**



* **P0-1 偏好充分应用**：将用户偏好稳定应用于回答风格与工具选择。

* **P1-1 主动提醒能力**：按要求提供定时 / 事件提醒。

* **P2-1 主动建议**：在合适场景给出建议。

**验收标准**：偏好稳定生效；提醒可用；建议有价值且不打扰。

## 五、验收标准汇总



1. UI 布局支持预览与前置校验，报错精确到节点；

2. 工具命名可区分、参数统一、返回结构一致；

3. 记忆可分类、有时效、按相关性注入、可自助管理；

4. 长对话关键信息不丢、任务状态清晰、可回滚；

5. 决策边界清晰、长任务进度可见、失败可恢复；

6. 文件易找到分享、格式可转换、有版本兜底；

7. 长任务有进度反馈、失败有统一重试；

8. 不可逆操作强制确认、敏感数据受控、防注入；

9. 语音交互顺畅、多模态边界清晰；

10. 偏好稳定生效、提醒与建议可用。
