# SmartQuiz 主题系统重构说明（v2 · Material You 动态色板）

> 重构时间：2026-09-07 · 范围：主题系统（深浅模式 / 主题色 / 动态色板 / 死代码清理）

## 一、为什么重构

原主题系统存在三类问题：

| 问题 | 原状 |
| --- | --- |
| 选色不生效 | ThemeActivity 选色只写 SharedPreferences + Toast，"保存"仅 finish()，主界面颜色不变 |
| 机制三套并存 | setDefaultNightMode（ThemeActivity）/ setTheme(显式 style)（ThemeManager，死代码）/ values-night 同名覆盖，深浅行为不可预测 |
| 冗余死代码 | ThemeSwitcherActivity、ThemeViewModel、ThemeRepository、ThemeAdapter、ThemeColorActivity、ThemeColorRepository、ThemeColorAdapter + 4 个布局，全部无入口或重复实现 |

## 二、新方案：Material You（Material 3 语义色板 + HCT 色彩空间）

采用 Google 官方最新设计体系（nowinandroid 同款思路），核心组件：

1. **色板引擎**：接入官方 **material-color-utilities**（Apache-2.0）Java 源码（9 个核心类），HCT 色彩空间从任意主色生成完整 M3 语义色板（primary/onPrimary/primaryContainer/.../surface/outline，浅深两套）。
2. **全局注入**：`SmartQuizApplication` 的 `onActivityPreCreated` 钩子对所有 Activity（无论继承关系）在 `setContentView` 之前 `applyStyle` 动态 ThemeOverlay —— 零侵入、切换即时生效、无需重启。
3. **资源 attr 化**：布局/drawable/styles 中 600+ 处主题色静态引用（`@color/primary` 等）批量替换为 `?attr/colorPrimary` 等 M2 标准主题属性，主题色变化时全局跟随。
4. **深浅模式统一**：三档（浅/深/跟随系统）全部走 `AppCompatDelegate.setDefaultNightMode` + DayNight 资源，删除 setTheme 显式 style 死路径。
5. **Compose 对齐**：ComposeTheme.kt 不再硬编码，运行时从 ThemeManager 取 HCT 动态色板生成 `lightColorScheme/darkColorScheme`，自定义色在 Compose 全量生效。

## 三、新架构

```
┌─ 存储层 theme_preferences ─────────────────────────────┐
│ current_theme (0/1/2) · current_theme_color_value(ARGB) │
│ custom_theme_color · use_custom_color（兼容旧数据迁移）   │
└─────────────────────────────────────────────────────────┘
                    │
┌─ ThemeManager（唯一入口）───────────────────────────────┐
│ 模式三档 · 主题色读写 · 色板缓存 · overlay 匹配 · 兼容迁移 │
└──────────────┬──────────────────────────────────────────┘
               │
   ┌───────────┼───────────────────┐
   ▼           ▼                   ▼
ThemeOverlay   ThemePalette       ThemePaletteProvider
(静态资源,     (M3 语义色板,      (HCT 算法,
 values +      浅/深两套)          官方 mcu 源码)
 values-night)
   │
   ▼
SmartQuizApplication.onActivityPreCreated
   → activity.getTheme().applyStyle(overlay, true)
   → 所有页面 setContentView 前已注入动态主题
   ├─ XML/View 体系：?attr/colorPrimary 等全局跟随（7 预设色全量）
   └─ Compose 体系：SmartQuizTheme → HCT 色板 → ColorScheme（预设+自定义全量）
```

## 六、扩展指南（给后期开发）

### 6.1 ThemeManager 公共 API（主题系统唯一入口）

**深浅模式**

| API | 说明 |
| --- | --- |
| `getMode(Context)` | 读三档模式（0 浅 / 1 深 / 2 跟随系统） |
| `setMode(Context, int)` | 设模式并即时作用于 AppCompat（自动重建界面）+ 通知监听 |
| `isDarkTheme(Context)` | 当前实际是否深色（含跟随系统时的 uiMode 判断） |

**主题色**

| API | 说明 |
| --- | --- |
| `getThemeColor(Context)` | 当前主题色 ARGB（优先自定义，兼容旧存储自动迁移） |
| `isCustomColor(Context)` | 是否自定义色 |
| `setThemeColor(Context, int)` | 选预设色（ARGB） |
| `setCustomThemeColor(Context, int)` | 设自定义色（ARGB） |
| `getThemeColorRes(Context)` | 兼容旧调用：主题色对应资源 id（自定义色返默认紫） |

**预设色注册表（单一数据源）**

| API | 说明 |
| --- | --- |
| `PRESETS`（List\<ThemePreset\>） | 全局预设色，UI 层遍历此列表 |
| `getPresets()` | 不可变预设色列表 |
| `getPresetByColor(int)` | 按 ARGB 精确查找（未命中返 null） |
| `ThemePreset` 字段 | `id` / `displayName` / `argb` / `overlayResId`（0=走色相网格） |

**皮肤包（多品牌皮肤）**

| API | 说明 |
| --- | --- |
| `SKINS`（List\<ThemeSkin\>） | 全部皮肤包（标准/军旅/校园…），新增在此追加 |
| `getSkins()` | 不可变皮肤包列表 |
| `getSkinById(String)` | 按 id 查找 |
| `getSkin(Context)` | 当前皮肤包（默认"标准"，异常自动回退） |
| `setSkin(Context, String)` | 切换皮肤：存值 + 主色重置为皮肤默认色 + 清缓存 + 通知监听 |
| `ThemeSkin` 字段 | `id` / `displayName` / `presets`（皮肤自带预设色）/ `defaultArgb` |

**色相网格（自定义色 / 皮肤扩展色 → XML 全量）**

| API | 说明 |
| --- | --- |
| `getHueOverlayResId(int)` | 任意 ARGB 就近映射 24 色相 overlay（HCT 感知色相，15° 一档） |

**动态色板与全局注入**

| API | 说明 |
| --- | --- |
| `getPalette(Context, boolean dark)` | 当前主题色完整 M3 色板（带缓存） |
| `clearPaletteCache()` | 清色板缓存（切色后调用，Compose 侧由主题监听自动处理） |
| `getOverlayResId(Context)` | 当前主题色静态 overlay 资源 id（自定义色=0） |
| `applyThemeOverlay(Activity)` | 注入主题到 Activity（Application 统一调用，一般无需手动） |

**主题变更监听（不重建场景）**

| API | 说明 |
| --- | --- |
| `registerThemeChangedListener(listener)` | 注册监听（任意线程、自动去重） |
| `unregisterThemeChangedListener(listener)` | 注销监听 |
| `notifyThemeChangedPublic(Context)` | 手动触发通知（壁纸变化等外部场景用；setXxx 已自动通知） |

**壁纸动态取色（Android 12+ Material You）**

| API | 说明 |
| --- | --- |
| `isWallpaperColorEnabled(Context)` | 壁纸取色是否开启 |
| `setWallpaperColorEnabled(Context, boolean)` | 开关壁纸取色（开启会清手动自定义色，进入动态模式） |
| `getWallpaperThemeColor(Context)` | 从系统壁纸提取主色 ARGB（无壁纸返回 0） |

主题色优先级：**自定义色 > 壁纸取色（开启时）> 预设色**；手动选色（setThemeColor/setCustomThemeColor）自动关闭壁纸取色。

监听回调 `onThemeChanged(int mode, int themeColor, boolean custom)`——Activity 场景切色/切模式会 recreate，监听主要给 **Compose 页面、Service、悬浮窗、运行中的对话框** 等不重建的组件用。示例：

```kotlin
// Kotlin / Compose：切色即时刷新，无需 recreate
DisposableEffect(Unit) {
    val l = ThemeManager.OnThemeChangedListener { _, _, _ -> /* 刷新 */ }
    ThemeManager.registerThemeChangedListener(l)
    onDispose { ThemeManager.unregisterThemeChangedListener(l) }
}
```

```java
// Java：Service / 悬浮窗等
ThemeManager.OnThemeChangedListener l = (mode, color, custom) -> { /* 刷新 */ };
ThemeManager.registerThemeChangedListener(l);
// ... 不需要时
ThemeManager.unregisterThemeChangedListener(l);
```

### 6.2 新增一个预设色（三步）

1. `ThemeManager.PRESETS` 追加一行：`new ThemePreset("red", "红色", 0xFFEF4444, R.style.ThemeOverlay_SmartQuiz_Red)`
2. 在 `ThemePreset` 所在包（`tools/`）重跑 overlay 生成器：
   ```powershell
   javac -encoding UTF-8 -d tools\mcu-out <mcu 全部 .java> tools\GenOverlays.java
   java -cp tools\mcu-out GenOverlays "D:\qzq\smartquiz\src\main\res"
   ```
3. 重新编译。主题页色块、overlay 注入、存储全部自动跟随——**无需改任何页面代码**。

> 若新增色的 `overlayResId` 填 `0`（不生成精确 overlay），自动走 24 色相网格近似，同样全量生效——适合皮肤包内扩展色（见 6.3 已实现项）。

## 八、已知限制

1. **自定义色 / 皮肤扩展色为 24 色相近似**：Android 静态 ThemeOverlay 无法程序化注入任意颜色，采用预生成 24 色相网格（每 15° 一档，HCT 感知色相）就近映射——XML 体系全量变色，色相正确、明度/饱和度取网格标准值（与用户精确 RGB 有轻微差异，视觉上属同一色系）。若需精确逐色，只能接入运行时 Resources 拦截（重型，不推荐）。
2. **MaterialSwitch 必须显式设 textOn/textOff**：material 1.12 + appcompat 1.7 的 SwitchCompat 在 textOn 为 null 时测量崩溃（StaticLayout NPE），主题页壁纸开关已规避（`android:textOn="开" android:textOff="关"` + `showText=false`）。**新增 Switch 控件务必遵守**，否则打开页面即崩。
3. **主色为 M3 Tone40 值**：HCT 生成的 primary 比所选色略深（Material 规范），整套配色和谐统一。
4. `Theme.SmartQuiz` / `Theme.SmartQuiz.Dark` style 保留未删（无引用），如需彻底清理可移除。
