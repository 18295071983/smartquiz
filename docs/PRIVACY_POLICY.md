# 答题宝（SmartQuiz）隐私政策

**更新日期：2026-10-24　生效日期：2026-10-24**

本政策适用于答题宝（包名 `com.oilquiz.app`，下称"本应用"）。请在使用前阅读；
继续使用即表示你已理解本政策。

> **一句话概括**：本应用**不运营收集用户数据的服务器**。你的题库、答题记录、AI 对话、
> 工作区文件默认只保存在本机；只有你主动使用联网功能时，相关内容才会发送到**你自己配置的
> 第三方服务**（模型服务商、天气、语音等），并受这些服务商自己的隐私政策约束。

---

## 一、默认只保存在本机的信息

下列信息由应用写入本机私有目录（`/data/data/com.oilquiz.app/` 与外部私有目录），
**不会自动上传到我们**：

- 题库、题目、答题记录与统计；
- AI 对话历史、附件、Agent 工作区文件（`files/`、`files/conversations/` 等）；
- 应用设置、主题、语言；
- 你填写的 API Key / 服务地址（用于调用你选择的模型服务）；
- 登录账号（邮箱 + 密码摘要，保存在本机 Room 数据库，仅用于本机身份校验）；
- 运行日志与崩溃日志（`files/ai_logs/`，仅本机留存，供你排查问题）。

删除方式见「六、你的权利」。

## 二、你主动发送到第三方的信息

以下内容**只在你主动操作时**才会离开设备，直接发送到**你自己选择的服务商**：

| 场景 | 发送内容 | 接收方 |
|---|---|---|
| AI 对话 | 你输入的文本、附加的图片/文件、工具调用参数与结果 | 你选择的模型服务商（OpenAI、DeepSeek、阿里百炼、智谱、腾讯混元、讯飞星火、火山方舟、百度千帆、MiniMax、Kimi、硅基流动、Anthropic、Google 等，或你自建的地址） |
| 在线语音识别 / 合成 | 录音片段或待合成文本 | 你配置的语音服务商（如阿里百炼 DashScope） |
| 天气 | 城市名称或定位坐标（取决于你授予的定位权限） | 和风天气（QWeather） |
| 联网搜索 / 网页抓取 / 文件下载 | 你给出的 URL 或关键词，以及目标站点的返回内容 | 对应网站或你配置的搜索服务 |
| 远程连接（remote_dsh） | 你主动发起的指令与目标主机信息 | 你指定的主机 / 中继 |

**我们不会**把这些内容另存到自有服务器，也不会用于训练、画像或广告。

## 三、权限清单与用途

| 权限 | 用途 | 是否必需 |
|---|---|---|
| 网络 / 网络状态 | 调用你配置的在线模型、天气、下载等 | 使用联网功能时必需 |
| 存储（读/写，含 Android 13 起的媒体权限） | 导入题库、读写工作区文件、导出/分享 | 使用文件功能时必需 |
| 相机 | 拍照/扫描二维码（远程配对、图片识别） | 可选，仅使用时申请 |
| 麦克风 | 语音输入、录音、语音识别 | 可选，仅使用时申请 |
| 定位（精确/粗略/后台） | 天气按位置、地图/位置卡片 | 可选；拒绝则需手动填城市 |
| 通讯录（读/写） | 联系人卡片的选取与保存 | 可选 |
| 电话（拨打/读取状态） | 一键拨号、通话状态判断 | 可选 |
| 通知 | 导出完成、提醒、播放控制通知 | 可选 |
| 悬浮窗（SYSTEM_ALERT_WINDOW） | 悬浮球/桌面小组件类系统工具 | 可选，需你在系统设置中授权 |
| 安装未知应用（REQUEST_INSTALL_PACKAGES） | 安装应用内导出的 APK、更新组件 | 可选 |
| 查询已安装应用（QUERY_ALL_PACKAGES） | 识别微信等第三方应用以完成对应集成 | 可选 |
| 前台服务（媒体播放/数据同步/屏幕共享等） | 后台播放、长任务、投屏 | 使用对应功能时必需 |
| 唤醒锁 / 忽略电池优化 | 保证长任务与后台播放不被系统中断 | 可选 |
| Termux RUN_COMMAND | 在你已安装 Termux 时执行本地命令 | 可选，仅在你授权 Termux 后生效 |

所有权限都可以在系统「设置 → 应用 → 答题宝 → 权限」中随时撤回；撤回后相关功能不可用，但不影响其他功能。

## 四、第三方 SDK 与组件

| SDK / 组件 | 用途 | 是否联网 | 说明 |
|---|---|---|---|

**本应用不集成**广告、统计埋点、崩溃上报类 SDK。

## 五、设备信息与安全

- **不收集** IMEI、MAC 地址、Android ID、OAID 等设备标识，不做跨应用追踪或用户画像；
- 与第三方服务的通信由其提供的 HTTPS 接口完成（以服务商实际配置为准）；
- 本机数据依赖 Android 应用沙箱隔离；请勿在 root 环境或非官方渠道安装包中存放敏感内容；
- 你填写的 API Key 保存在本机应用私有目录，请勿分享截图或日志中的 Key。

## 六、你的权利

- **查询/导出**：题库可在应用内查看、导出（Excel/PDF/Markdown 等）。
- **删除**：应用内「清空历史」删除对话；「回收站」可彻底删除会话；
  卸载应用会删除应用私有目录内的全部数据（工作区中你手动导出到公共目录的文件除外）。
- **撤回授权**：在系统权限设置中关闭任一权限。
- **注销账号**：本应用账号仅存于本机，删除应用数据即等同于注销。
- 由于我们不运营服务器，**无法远程查看或删除你的数据**——删除只能在本机完成。

## 七、未成年人保护

本应用面向学习场景，不面向儿童投放广告或进行画像。若你未满 14 周岁，请在监护人指导下使用；
涉及在线模型、联网搜索、文件下载等功能时，建议由监护人代为配置与把关。

政策更新会随应用版本发布，并更新本页顶部的「更新日期」。若涉及重大变更，会在应用内提示。
