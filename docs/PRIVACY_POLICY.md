# 答题宝（SmartQuiz）隐私政策与免责条款

**更新日期：2026-11-13　生效日期：2026-11-13**

本政策适用于答题宝（包名 `com.oilquiz.app`，下称"本应用"）。请在使用前完整阅读；
你点击「同意并继续」或继续使用，即表示已理解并接受本政策与第十节免责条款。

> **一句话概括**：本应用**不运营收集用户数据的服务器**。题库、答题记录、AI 对话、工作区文件
> 默认只保存在本机；只有你主动使用联网功能时，相关内容才会发送到**你自己配置的第三方服务**
> （模型服务商、天气、语音、搜索、远程主机等），并受这些服务商自己的隐私政策约束。

---

## 一、适用范围

本政策覆盖本应用内的全部功能，包括：本地题库与答题、AI 对话与 Agent 工具、文档/音视频处理、
端侧模型推理，以及「远程连接（remote_dsh）」——通过局域网或你配置的隧道连接到你自己的电脑端
DeepSeek Harness（DSH）。

**不适用**于：你通过本应用访问的第三方服务、你自行安装的组件（如 Termux）、你连接的电脑端主机——
这些由对应服务方或你本人负责。

## 二、默认只保存在本机的信息

下列信息写入本机私有目录（`/data/data/com.oilquiz.app/` 与外部私有目录），**不会自动上传**：

- 题库、题目、答题记录与统计；
- AI 对话历史、附件、Agent 工作区文件（`files/`、`files/conversations/` 等）；
- 应用设置、主题、语言、界面偏好；
- 你填写的 API Key、服务地址、远程连接令牌与配对信息；
- 登录账号（邮箱 + 密码摘要，仅用于本机身份校验）；
- 运行日志与崩溃日志（`files/ai_logs/`，仅本机留存，供你排查问题）；
- 端侧模型文件与推理缓存。

删除方式见「七、你的权利」。

## 三、你主动发送到第三方的信息

以下内容**只在你主动操作时**才会离开设备，直接发送到**你自己选择的服务方**：

| 场景 | 发送内容 | 接收方 |
|---|---|---|
| AI 对话 | 输入文本、附加的图片/文件、工具调用参数与结果、上下文 | 你选择的模型服务商（OpenAI、DeepSeek、阿里百炼、智谱、腾讯混元、讯飞星火、火山方舟、百度千帆、MiniMax、Kimi、硅基流动、Anthropic、Google 等，或你自建地址）|
| 在线语音识别/合成 | 录音片段或待合成文本 | 你配置的语音服务商（如阿里百炼 DashScope）|
| 天气 | 城市名称或定位坐标（取决于定位权限）| 和风天气（QWeather）|
| 联网搜索 / 网页抓取 / 文件下载 | 你给出的 URL 或关键词，及目标站点返回内容 | 对应网站或你配置的搜索服务 |
| **远程连接（remote_dsh）** | 你在手机上发起的指令、对话内容、审批决定；电脑端回传的事件 | **你自己的电脑**（局域网地址或你配置的隧道域名）；若使用第三方隧道，流量经过该隧道服务商 |
| 屏幕共享 / 投屏（如使用）| 你选择共享的屏幕内容 | 你指定的接收端 |
| 应用内导出/分享 | 你选中的文件或文本 | 你在系统分享面板中选择的应用 |

**我们不会**把这些内容另存到自有服务器，也不会用于训练、画像或广告。

> 提示：远程连接默认走**局域网直连**（HTTP + 令牌校验）。若你在不可信网络中使用，建议改用
> 你自建或信任的 HTTPS 隧道，并定期更换令牌。

## 六、设备信息与安全

- **不收集** IMEI、MAC 地址、Android ID、OAID 等设备标识，不做跨应用追踪或用户画像；
- 与第三方服务的通信由其 HTTPS 接口完成（以服务商实际配置为准）；
- 远程连接令牌保存在本机；请勿分享截图或日志中的地址与令牌；
- 本机数据依赖 Android 应用沙箱隔离；请勿在 root 环境或非官方渠道安装包中存放敏感内容；
- 应用崩溃日志仅保存在本机，不会自动上传。

## 七、你的权利

- **查询/导出**：题库可在应用内查看、导出（Excel/PDF/Markdown 等）。
- **删除**：应用内「清空历史」删除对话；「回收站」可彻底删除会话；卸载应用会删除应用私有目录内的
  全部数据（你手动导出到公共目录的文件除外）。
- **撤回授权**：在系统权限设置中关闭任一权限；在应用内「撤回隐私同意」可重置本机同意状态。
- **注销账号**：本应用账号仅存于本机，删除应用数据即等同于注销。
- 由于我们不运营服务器，**无法远程查看或删除你的数据**——删除只能在本机完成。

## 八、未成年人保护
