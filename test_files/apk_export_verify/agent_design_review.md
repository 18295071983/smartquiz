## 一、先说结论

功能完整度没问题，**四条来源 + 三种图标 + 中文全链路都能跑通**。但从"设计"角度看，有 **1 个灾难级缺陷 + 3 个体验级缺陷**。

### 做得好的地方（别改坏）
- ✅ 路径穿越已防护：`apk_name=../../traversal_probe` 被净化，无文件逃逸。
- ✅ 图标做了魔数校验：JPEG 改名成 `.png` 也能被识破。

## 三、核心建议（如果只改一处，改这个）

### 让每个导出包拥有独立 applicationId

**为什么是它**：这是唯一一个"用户会真实丢东西且毫无提示"的问题。因为包名和签名都相同，Android 不会报"签名冲突"，而是**当作版本升级直接覆盖安装**——用户的第一个作品就没了，还找不到任何错误信息。

**落地路径（三档，按成本选）**

1. **低成本 · 当天可做**：不改包名，但
   - 导出返回值/UI 中明确警告"同名应用互斥，安装将覆盖此前导出"；
   - 把 `apk_name` 或时间戳写进 `versionName`，让用户至少能分辨。
2. **推荐 · 一两天**：
   - 壳模板预留**等长占位包名**（如 `com.cjhtmldemo.xxxxxxxxxxxxxxxx`），manifest 的 `package` 字段在 AXML 字符串池中做**等长替换**（无需重编译 AXML）；
   - 按 `apk_name` 派生 slug 填入，`zipalign` + `apksigner` 用同一 keystore 重签；
   - 结果：每包独立 applicationId，**可同时安装共存**，且因为你复用同一 keystore，同包名的"升级覆盖"语义依然保留。
3. **彻底**：每包独立 applicationId + 独立签名（动态生成 keystore），彻底隔离，但失去升级覆盖便利。

> ⚠️ 顺带提醒：现在用的是**自签证书**（CN=smartquiz），上架/分发场景要注意证书有效期到 2036-07-17，且务必**离线备份 keystore**，否则后续无法升级已装应用。

## 四、其余修复建议（按优先级）

| 编号 | 建议 | 实现要点 |
|------|------|----------|
| R1 | 临时目录隔离 | 目录名加 `taskId`/UUID 后缀；`try/finally` 清理；失败自动重试 1 次；必要时加全局互斥锁串行化 |
| R2 | 应用名文案与报错 | 文档改"UTF-8 字节 ≤22（中文≈7 字）"；报错补"当前 X 字节 / 上限 22"。**根治方案**：不再打 AXML 补丁，改为壳启动时读 `assets/manifest.json` 的 `label` 字段动态 `setTitle()`——彻底移除长度上限（现方案每改一次上限就要重建壳模板，`apk_shell_meta.json` 里那句"重建壳模板后需重新运行 gen_meta.py"就是这个脆弱点的自白） |
| R3 | 来源参数互斥 | `url/html/html_file/html_dir` 四选一，多传直接报错并说明优先级 |
| R4 | url 模式跳过 libs 注入 | 仅在本地模式注入；进一步支持 `libs:["vue","echarts"]` 按需注入，减少基线体积 |
| R5 | 图标规格 | 校验 ≥192×192 方形（<512 时给出提示）；自动生成 mipmap 多密度；接受 JPG/WebP 自动转 PNG |
| R6 | 返回元数据 | 返回 `{path,size,apk_name,app_name,package,versionName,versionCode,signerSha256,sha256}` |
| R7 | 版本控制 | 增加 `version_name`/`version_code` 参数（壳模板同样预留等长占位） |
| R8 | 载荷策略 | 明确 `dt.jet` 加密目标并写进文档；若无需防盗，改明文 `assets/www/`（WebView 原生支持 `file:///android_asset/www/index.html`，可调试、可压缩）；若保留加密，建议 AAD + 每包派生密钥 |

## 五、验收清单（改完可以照这个测）

1. 连续导出 3 个不同 `apk_name` 的包 → 手机里**能同时装上 3 个**，图标/应用名各自正确。
2. 并发导出 3 个 → **全部成功**，无"无法创建临时目录"。
3. 应用名填 8 个汉字 → 报错明确写出"24 字节 / 上限 22 字节"。
4. `html_file` + `html_dir` 同传 → 明确报错。
5. 32×32 图标 → 被拒或给出"图标过小"提示。
6. url 模式导出包 → assets 内**无** `libs/` 目录。
7. 返回值包含 package / versionName / sha256。
8. `../../` 路径穿越仍然被净化（回归）。
