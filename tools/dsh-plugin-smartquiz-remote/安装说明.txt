SmartQuiz Remote —— DSH 原生插件（装在电脑的 DeepSeek Harness 上）
================================================================
版本：0.3.2（插件内部 v8）
  · v8 新增「自检 + 双端对账」：/health 自检（cwd/dsh_home/preset/exec）、/reconcile 逐条对账、/ack 回执水位线
  · v8 修 cwd 静默降级：工作目录无效时不再无声继承宿主 cwd，降级事实写入 /health
  · v7 修「直连模式电脑容易卡」：CLI 子进程单并发 + 手机超时/断开即杀整棵进程树 + 低优先级

【这是什么】
  一个 DSH 宿主插件：让答题宝手机端与电脑上的 DSH 双向打通。
  ✔ 手机发消息 → 电脑那条对话里执行，回复/思考/工具卡同步回手机
  ✔ 电脑端在跑的过程（第几步、正在运行哪个工具）手机能看到
  ✔ 审批双端弹窗，谁先点谁生效
  ✔ 电脑端对话历史可一键导入手机（离线可看）
  ✔ 手机切后台/锁屏仍能收（前台服务 + 通知栏）
  ✔ 断线续传：App 被杀/网络断了，回来按进度补拉，不丢消息
  ✔ 不需要 Python        ✔ 自带局域网入口(8218)  ✔ 配对二维码 + 设备令牌鉴权

【怎么装】（在电脑上，30 秒）
  1. 把本 plugin 文件夹整个拷到电脑任意位置，例如：
        D:\smartquiz-remote
  2. 打开 DSH → 插件管理器 → 「从文件夹安装」→ 选择上面的文件夹
     （命令行等价：dsh plugin --profile desktop add "D:\smartquiz-remote"）
  3. 重启 DSH（替换已安装的包必须重启才会加载新的 JS 模块）
  4. 重启后在 DSH 输入框上方点「📱 手机远程」→「在电脑上打开配对页」
     → 页面上会出现二维码（局域网 + 隧道，有几个可达地址就有几张）
  5. 手机：答题宝 → 工具集 → 设置与数据 → 远程连接（电脑）→ 扫码配对

【手机怎么用】
  · 同步模式（推荐）：选一条电脑会话后，手机发的话进电脑「同一条对话」，
    电脑上能看到、手机也能看到回复与工具卡
  · 直连模式：电脑上一条**专属于手机**的对话（默认一条），不打断电脑当前对话。
    手机与电脑协商同一个电脑会话 id；「远程连接（电脑）」页可设「直连对话码」
    （如 work）分成多条 —— 重装后填回同一个码就能接回原来那条对话。
    电脑上正看着这条对话时也可以发：会自动改走宿主内投递，消息实时出现在电脑那条对话里
  · 导入历史：「远程连接（电脑）」→ 选会话 →「把电脑这条对话的历史导入本机」
  · 审批：电脑弹审批时手机同时弹，点哪边都行，另一端自动消失

【端口与地址】
  · 局域网：http://<电脑局域网IP>:8218   （插件自建，0.0.0.0 监听）
  · 公网：  用花生壳/frp/Tailscale 把 8218 映射出去，把域名填进插件配置的 publicUrl
             （也可在插件目录建 .public-url 文件写一行域名）
  · 令牌：  插件目录下的 .token（自动生成、持久保存）；也可用一次性配对码换取设备令牌

【安全默认】
  · 令牌鉴权（Bearer）；/devices 可查看并单独吊销设备
  · /exec（电脑直连执行命令）默认关闭，需要时在插件面板里开，或配置 allowExec: true
  · 反向指令（电脑 → 手机）只放行 4 个纯 UI/轻状态工具：
      ui_component / ui_component_plugin / task / reminder
  · 不会把 DSH 的 Web 界面暴露到局域网（插件只暴露自己的接口）
  · 手机端会话列表只显示"活跃"会话（归档的、没有标题也没有消息的空会话不列出）

【协议 v2（v8.2 起，双端同源）】
  · GET  /v2/session?code=  会话身份权威：返回 { id, bound, needs_first_message, live, execution }
  · POST /v2/session        { action: 'state'|'list'|'attach', code?, session_id?, bind? }
                            会话 id 永远由电脑签发；手机只持"对话码"，换机/重装都能接回同一条对话
  · 手机端 SDK：RemoteSdk.java（hello / sessionState / listSessions / attach / view / send / ack / reconcile / events / streamUrl）
  · 手机端事件流：RemoteStream.java（读 SSE，断连自停、超时自结束）；工具 action=events 按 since 增量拉事件
  · GET  /v2/schema   字段字典：sessions_count / plugin_sessions / active_jobs / last_seq / acked_seq / digest / execution / verdict
  · POST /v2/hello    握手 + 能力协商（返回 capabilities / features / limits）
  · GET  /v2/view     服务端派生 ViewModel：{ header, cards[] }
                      cards.kind = status(rows) | checks(items) | session(rows) | timeline(messages)
                      电脑面板与手机页面渲染同一份，文案只在服务端定义一次
  · POST /v2/message  { session_id, text, stream?, timeout? } 复用 legacy runPrompt（CLI/宿主内两条路），响应头 x-dsh-protocol: 2
  · GET  /v2/stream?session_id=&since=   SSE 事件流：先按 since 回放，再 1.5s 增量 + 保活；信封 { v, seq, id, ts, type, data }
  · POST /v2/ack / POST /v2/reconcile    与 /ack /reconcile 同一实现（无双份代码）
  · /status 新增 text_lines：计数类文案由服务端给，手机不再自己拼（旧客户端自动退回本地格式）
  · 消息来源台账：.origins.jsonl 记录"插件代手机发送"的（会话id + 文本hash + 时间），
                    /v2/view 时间线每条消息带 origin=phone|desktop，两端显示「你(手机)」「你(电脑)」
                    匹配规则：同会话 + 同文本 + 10 分钟窗口内 → phone，否则 desktop（启发式）

【自检与双端对账（v8）】
  · GET  /health（带令牌或本机）→ checks[]：host_cwd / dsh_home / exec_channel / agent_preset / session_mount
      host_cwd 红 = 宿主工作目录不是真实目录，所有起子进程的工具都会报 ENOENT（看着像 powershell/rg 丢了）
  · POST /ack { session_id, seq?, ids?[] } → 回执水位线，落盘 .acks.json，只增不减
  · POST /reconcile { session_id, messages?, digest?, last_seq?, acks?, light? }
      light=1 → 只回 { digest, last_seq, event_count, message_count } + 当前回执，适合定时轮询
      传 messages[] → 逐条比对，返回 verdict(match|diverged) + first_divergence + missing_on_client / extra_on_client
      digest 算法：sha256(每条消息 "role\0text" 顺序拼接、换行分隔)，手机端可用同样算法离线自校验
  · 推荐时序：手机每 30s 拉 light 摘要 → digest 不一致才拉全文 → 修完立刻 POST /ack 推进水位线

【排查】
  · 手机上"探测桥接失败"：① 先确认地址端口 ② 局域网需同一网段 ③ 公网需隧道映射到 8218
    ④ Windows 防火墙放行入站 8218
  · 走了隧道还是连不上：确认映射的"内网服务"填的是 127.0.0.1:8218
  · 面板显示「隧道域名：未设置」：在面板里填域名，或写插件目录 .public-url 文件
  · 电脑上执行报"沙箱无法授权某盘根目录"：把任务范围放到你自己的目录（如 D:\qzq），
    或给该盘根目录授予当前账号完全控制；手机直连模式已默认用 danger-full-access 运行
