## 工具调用完整流程

```
用户消息 → Agent分析意图 → 生成TOOLS_CALL命令 → 工具执行器执行 → 等待结果
    ↓
分析结果是否满足需求 → 不满足：调整参数重试 → 满足：继续
    ↓
整合所有工具结果 → 生成最终回答 → 清理内部缓存 → 等待下一次调用
```

## 问题诊断

### 1. 流式推理内容不显示
- `UnifiedAgentEngine` 通过 `callback.onToken()` 发送流式token
- `AgentChatHandler` 转发到 `AIChatActivity` 的 `onToken()` 回调
- **问题**: Agent模式下，`onToken` 只更新了 `currentStreamingContent`，但没有更新当前streaming message的content到UI
- **根本原因**: Agent的token通过engine的callback传递，但AIChatActivity的`onToken`回调中的 `safeUpdateMessage()` 只在普通聊天模式下正确工作，Agent模式下streaming message的更新逻辑不完整

### 2. Token统计未连接
- `TokenStatsManager` 已存在，支持`updateRequestStreamingStats`和`updateRequestStats`
- **问题**: Agent模式下(`UnifiedAgentEngine`和`AgentChatHandler`)从未调用`TokenStatsManager`
- **结果**: Agent模式下token统计为0，推理速度不显示

### 3. Agent执行链中断原因
- **MAX_PROMPT_LENGTH = 8000**: 当prompt（包含工具列表+上下文+用户消息）超过8000字符时被截断
- **MAX_CONTEXT_ENTRIES = 20**: 上下文条目超过20时被裁剪
- **toolLoopCount >= maxToolLoops(5)**: 工具调用超过5次后强制总结
- **contextSummary中的长文本**: 工具结果可能很长（`TOOL_RESULT_MAX_LENGTH=1500`），累积后prompt超长
- **Activity销毁**: `isValid()` 返回false导致回调被跳过
- **chatSend错误**: 本地模型推理出错时直接`finishGeneration`

### 4. 工具调用机制
- **工具发现**: `AgentService.autoDiscoverToolSchemas()` 自动发现已注册工具
- **工具列表提示**: `buildToolListPrompt()` 生成工具描述注入prompt
- **调用格式解析**: `parseToolCalls()` 支持8种格式（TOOLS_CALL/JSON/markdown等）
- **工具执行**: `executeToolWithTimeout()` 带超时和重试
- **结果传递**: 工具结果追加到`contextSummary`，作为下一轮推理的上下文
- **问题**: 工具结果没有被结构化解析，只是简单截断后作为字符串传递

```java
private void trimContextIfNeeded() {
    synchronized (contextSummary) {
        if (contextSummary.size() > MAX_CONTEXT_ENTRIES) {
            int toRemove = contextSummary.size() - MAX_CONTEXT_ENTRIES;
            for (int i = 0; i < toRemove; i++) {
                contextSummary.remove(0);
            }
        }
        int totalChars = 0;
        for (String entry : contextSummary) {
            totalChars += entry.length();
        }
        while (totalChars > CONTEXT_TRUNCATE_THRESHOLD && contextSummary.size() > 5) {
            String removed = contextSummary.remove(0);
            totalChars -= removed.length();
        }
    }
}
```

3. **错误恢复：返回部分结果**:
```java
@Override
public void onError(String error) {
    if ("[TOOL_CALL]".equals(error)) {
        handler.onToolCallDetected(currentResponse.get().toString());
        return;
    }
    if (shouldRetryContextError(error)) {
        AILogger.w(TAG, "Context error, attempting recovery...");
        contextInitialized.set(false);
        try {
            UnifiedContextManager ctxManager = getContextManager();
            if (ctxManager != null) {
                ctxManager.checkAndRecoverAllIfNeeded(aiService);
                if (ensureChatContextReady(handler)) {
                    sendAndProcessWithLocalModel(message, maxTokens, enableThinking, handler);
                    return;
                }
            }
        } catch (Exception e) {
            AILogger.w(TAG, "Recovery failed: " + e.getMessage());
        }
    }
    // 【核心】返回部分结果而非完全失败
    String partialResponse = currentResponse.get().toString();
    if (partialResponse != null && !partialResponse.isEmpty()) {
        AILogger.w(TAG, "Returning partial response due to error: " + error);
        handler.onFinalResponse(partialResponse);
    } else {
        finishGeneration();
        notifyError("执行中断: " + error);
    }
}
```

### Phase 4: 工具调用结果智能摘要（处理长结果）

**目标**: 当工具返回大量文本时（如搜索结果），使用LLM智能摘要，保留关键信息

**修改文件**:
- `AgentService.java` - 添加智能摘要方法
- `UnifiedAgentEngine.java` - 对长结果使用摘要

**关键改动**:

1. **AgentService添加智能摘要方法**:
```java
/**
 * 对长工具结果进行智能摘要
 * 当结果超过阈值时，使用LLM生成简洁摘要
 */
private static final int TOOL_RESULT_SUMMARY_THRESHOLD = 1500; // 超过此长度触发摘要

public String summarizeToolResult(String toolName, String result) {
    if (result == null || result.length() <= TOOL_RESULT_SUMMARY_THRESHOLD) {
        return result; // 短结果直接返回
    }
    
    try {
        // 构建摘要prompt
        String summaryPrompt = "请对以下" + toolName + "工具的返回结果进行简洁摘要，"
            + "保留关键信息，去掉无关内容，控制在500字以内：\n\n"
            + result.substring(0, 3000); // 截取前3000字符给LLM
        
        // 使用AI服务生成摘要（同步调用）
        String summary = aiService.generateSync(summaryPrompt, 500);
        if (summary != null && !summary.isEmpty()) {
            AILogger.i(TAG, "Tool result summarized: " + result.length() + " -> " + summary.length());
            return "[摘要] " + summary;
        }
    } catch (Exception e) {
        AILogger.w(TAG, "Failed to summarize tool result: " + e.getMessage());
    }
    
    // 摘要失败，使用固定截断
    return result.substring(0, TOOL_RESULT_MAX_LENGTH) + "...[已截断]";
}
```

2. **UnifiedAgentEngine使用智能摘要**:
```java

public String formatWeatherResult(String result) {
    try {
        org.json.JSONObject json = new org.json.JSONObject(result);
        String city = json.optString("city", "未知");
        int temp = json.optInt("temp", 0);
        String desc = json.optString("description", "");
        int humidity = json.optInt("humidity", 0);
        return String.format("%s天气: %s, 温度%d°C, 湿度%d%%", city, desc, temp, humidity);

        return result.length() > 500 ? result.substring(0, 500) + "..." : result;
    }
}
```

```java
// 在ChatAdapter的AgentStepViewHolder中
class AgentStepViewHolder extends RecyclerView.ViewHolder {
    TextView stepTypeText;
    TextView stepDetailText;
    TextView progressText;    // 新增：进度文本
    ProgressBar progressBar;  // 新增：进度条
    TextView executionTimeText; // 新增：执行时间
    
    void bind(ChatMessage message) {
        AgentStepInfo info = message.agentStepInfo;
        if (info != null) {
            stepTypeText.setText(info.getStepTypeLabel());
            stepDetailText.setText(info.thought != null ? info.thought : info.detail);
            
            // 显示进度
            if (info.totalIterations > 0) {
                progressText.setText(String.format("步骤 %d/%d", info.iteration, info.totalIterations));
                progressText.setVisibility(View.VISIBLE);
                progressBar.setMax(info.totalIterations);
                progressBar.setProgress(info.iteration);
                progressBar.setVisibility(View.VISIBLE);
            } else {
                progressText.setVisibility(View.GONE);
                progressBar.setVisibility(View.GONE);
            }
            
            // 显示执行时间
            if (info.executionTimeMs > 0) {
                executionTimeText.setText(String.format("耗时: %.1fs", info.executionTimeMs / 1000.0));
                executionTimeText.setVisibility(View.VISIBLE);
            }
        }
    }
}
```
