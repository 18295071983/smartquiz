# 🕒 Fliko

> **Time, Beautifully Flipped.**

Fliko is a premium flip clock web application built entirely with **HTML, CSS, and Vanilla JavaScript**. It recreates the classic mechanical flip clock with smooth 3D animations while offering modern features such as world clocks, themes, fullscreen mode, screensaver mode, timers, and extensive customization—all in a single HTML file.

---

## ✨ Features

### 🕒 Realistic Flip Clock
- Authentic mechanical flip-card animation
- Smooth 3D CSS transforms
- Real-time updates every second
- 12-hour & 24-hour formats
- Optional AM/PM display
- Optional seconds display
- Optional milliseconds display
