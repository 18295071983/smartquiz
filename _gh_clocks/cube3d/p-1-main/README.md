# 🧊 Cube Clock – 3D Flip Clock (Black Theme)

A stylish **3D cube flip clock** built using **pure HTML, CSS, and JavaScript**.  
It displays **hours, minutes, and seconds** using animated rotating cubes inside a 3D room with a dark, cinematic aesthetic.

No libraries. No frameworks. Just clean frontend magic ✨

---

## 🔥 Features

- ⏰ Real-time digital clock (Hours / Minutes / Seconds)
- 🧊 Smooth 3D cube flip animation
- 🌑 Dark / black theme with depth shadows
- 🎨 Pure CSS 3D transforms & gradients
- ⚡ Lightweight and fast (no dependencies)
